# VANTA Remote

مشروع Android مبدئي بواجهة عربية. هذه النسخة قابلة للبناء والتثبيت، لكنها لا تنفذ اتصالًا أو تحكمًا عن بُعد بعد.

## الموجود
- شاشة رئيسية عربية.
- أزرار واجهة للربط ومشاركة الشاشة وإيقاف الاتصال.

## ما لم يكتمل
- الاقتران الفعلي بين جهازين.
- بث الشاشة عبر Android MediaProjection.
- قناة اتصال WebRTC وربطها بخادم signaling.
- التحكم الفعلي المصرح به.

## البناء
يتطلب JDK 17 وAndroid SDK 35.
