# VANTA Remote

تطبيق Android باسم VANTA وهوية MANW 😈💪، بواجهة عربية داكنة.

## الموجود في الكود الحالي
- إنشاء رمز ربط من 6 خانات والاتصال بخادم الإشارات عبر WebSocket.
- تبادل WebRTC offer/answer وICE.
- التقاط الشاشة عبر Android MediaProjection بعد موافقة المستخدم.
- عرض بث الشاشة على الجهاز المتصل.
- إرسال نقرات لمس من الجهاز المشاهد إلى الجهاز المضيف عبر DataChannel وAccessibilityService.

## متطلبات الاستخدام
1. ثبّت APK على الجهازين.
2. على الجهاز الذي سيشارك شاشته: أنشئ رمز ربط وشاركه مع الجهاز الآخر.
3. على الجهاز الآخر: أدخل الرمز.
4. على الجهاز المضيف: وافق على طلب مشاركة الشاشة من Android.
5. إذا أردت التحكم بالنقر، فعّل خدمة VANTA يدويًا من إعدادات إمكانية الوصول على الجهاز المضيف.

## الخادم
خادم الإشارات موجود في `server/` ويعمل على Railway عبر:
- WebSocket: `wss://vanta-remote-server-production.up.railway.app/ws`
- Health: `https://vanta-remote-server-production.up.railway.app/health`

الخادم يمرر رسائل التفاوض فقط؛ لا ينقل فيديو الشاشة بنفسه.

## حدود النسخة الحالية
- الاتصال يستخدم STUN عام فقط؛ بعض الشبكات تحتاج TURN حتى ينجح الاتصال.
- التحكم الحالي يدعم النقر فقط، وليس السحب أو لوحة المفاتيح.
- رموز الربط ليست مصادقة قوية ولا يوجد انتهاء صلاحية أو حماية إنتاجية كاملة.
- نجاح البناء لا يثبت نجاح الاتصال على كل الأجهزة والشبكات. يجب اختبار مشاركة الشاشة والتحكم على جهازين فعليين قبل اعتبارها نسخة إنتاجية.

## البناء
يتطلب JDK 17 وAndroid SDK 35. GitHub Actions يبني Debug APK ويرفعه كـ artifact باسم `VANTA-Remote-debug-apk`.
